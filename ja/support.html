よくある質問

配信者をリストに追加するには？

ツールバーから拡張機能を開き、追加欄に Twitch または Kick のチャンネル名を入力して確定します。配信状況はすぐに表示されます。

データは収集されますか？

いいえ。設定、視聴時間、ポイントはブラウザ内にローカル保存されます。Twitch と Kick の公開 API に送られるのは、フォロー中のチャンネル名だけで、配信状況の確認に使われます。

チャンネルが配信中と表示されない場合は？

チャンネル名のつづりを正確に確認し、更新まで数秒お待ちください。それでも直らない場合は、プラットフォームとチャンネル名を添えてフォームからご連絡ください。

StreamPulse は無料ですか？

はい、完全に無料です。アカウント登録も広告もありません。

Drops と Moments の自動取得はどう動きますか？

StreamPulse はチャンネルポイントの宝箱、進行中の Twitch Drops キャンペーン、Moments バッジを検出します。すべてバックグラウンドで自動取得され、操作は不要です。履歴は拡張機能のログで確認できます。

フローティングの予測オーバーレイの使い方は？

Twitch の配信で予測が始まると、プレーヤー上に半透明のパネルが表示されます。投票、オッズと残り時間の確認ができ、オーバーレイはいつでも移動または非表示にできます。

タブのアイコンが変わるのはなぜですか？

設定で有効にすると、StreamPulse はタブのファビコンを配信中の配信者のプロフィール画像に置き換え、角に赤い LIVE ドットを表示します。どのタブが配信中かひと目で分かります。
