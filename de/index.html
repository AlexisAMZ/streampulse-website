FAQ

Häufige Fragen.

Ist StreamPulse kostenlos? +
Ja, 100 % kostenlos und das bleibt so. Keine Funktion hinter einer Paywall, kein Abo, keine versteckten Kosten.
Welche Plattformen werden unterstützt? +
Twitch (mit allen Funktionen), Kick (Live-Tracking + Benachrichtigungen). Weitere Plattformen werden geprüft.
Werden Punkte im Hintergrund gesammelt? +
Ja. StreamPulse sammelt deine Kanalpunkte automatisch, sobald sie verfügbar sind, auch ohne offenen Twitch-Tab. Ein Zähler zeigt dir die Summe.
Braucht die Erweiterung viele Ressourcen? +
Nein. Sie ist optimiert (Debouncing, intelligenter Cache, leichte Architektur). Speicher- und CPU-Bedarf sind minimal.
Kann ich einzelne Funktionen abschalten? +
Natürlich. Jedes Modul (Benachrichtigungen, Punkte, Auto-Reload, Filter) lässt sich in den Einstellungen einzeln an- und abschalten.
Sind meine Daten sicher? +
StreamPulse erfasst keine personenbezogenen Daten. Alles wird lokal in deinem Browser gespeichert. Keine Übertragung an unsere Server oder Dritte.
Wie installiere ich die Twitch Erweiterung in Chrome? +
Öffne die StreamPulse Seite im Chrome Web Store, klicke auf Hinzufügen und bestätige. Die Erweiterung ist sofort aktiv, ohne Konto und ohne Neustart des Browsers.
Funktioniert die Erweiterung in Edge, Brave und Opera? +
Ja. Diese Browser basieren auf Chromium und akzeptieren Erweiterungen aus dem Chrome Web Store. Erlaube in Edge zuvor Erweiterungen aus anderen Stores.
Was ist die beste Twitch Erweiterung für Kanalpunkte? +
Das hängt von deiner Nutzung ab. StreamPulse richtet sich an regelmäßige Zuschauer: Punkte auch bei geschlossenem Tab, Live Benachrichtigungen und automatische Drops in einer Erweiterung statt in dreien.
Bremst die Erweiterung den Browser aus? +
Nein. Die Module bleiben inaktiv und laufen nur bei Bedarf. Zusätzlich lässt sich jede Funktion einzeln abschalten.
