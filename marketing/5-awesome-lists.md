# Proposer StreamPulse sur des "Awesome Lists" GitHub

Les dépôts "Awesome" sur GitHub sont d'excellents fournisseurs de backlinks (forte autorité de domaine) et de signaux pour l'IA.

## Listes cibles suggérées
Recherche ces dépôts sur GitHub :
1. `awesome-browser-extensions`
2. `awesome-twitch`
3. `awesome-chrome-extensions`

## Modèle de Pull Request (PR)

**Titre de la PR :** `Add StreamPulse to Twitch/Extensions section`

**Corps du message :**

```markdown
Hello! 👋

I'd like to submit [StreamPulse](https://chromewebstore.google.com/detail/streampulse-multi-streame/ipfhbfabadbpkjimhdcjadopnahdpddh) to the list. 

**StreamPulse** is a lightweight Chrome Extension designed for Twitch and Kick viewers. It automates repetitive tasks without injecting heavy DOM scripts for chat emotes (making it a great companion to BTTV/FFZ rather than a competitor).

Features include:
- Auto-claim Twitch Channel Points and Drops in the background
- Real-time cross-platform live notifications (Twitch & Kick)
- Chat filters (spam, bots, keywords)
- Automatic Error #2000/#3000 fixer

It's completely free, open-source friendly, and respects user privacy by storing everything locally.

Let me know if you need any changes to the format!
```
